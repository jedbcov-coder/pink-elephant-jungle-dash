# Developer Workspace

Project-local creative and reference workbench.

Use this directory for exploratory assets, screenshots, captures, PDFs,
generated references, rough designs and other project-specific material that
should remain local and non-authoritative.

Contents are ignored by Git by default.

This directory is not a substitute for `Scratch`. Use the DevHut Scratch
estate for disposable operational staging, downloads and bulk/non-curated
exports.

Material that becomes durable or authoritative must be promoted deliberately
to the appropriate tracked project location.
